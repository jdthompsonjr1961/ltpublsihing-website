# LT Publishing redesign — Phase 3

Upload the contents of this folder to the root of `site-redesign`.

This phase:
- groups homepage books by imprint, with ranking inside each imprint;
- restores the publishing philosophy for LT Publishing and LT Select;
- reframes Services around fair, scoped work rather than price packages;
- changes the Authors page to “Distinct voices. One standard of care.”;
- restores Belle Époque Editions as a full imprint;
- adds `submissions.html`;
- uses the existing Formspree endpoint: `https://formspree.io/f/mkoyndwz`;
- adds Submit Your Work to the navigation.

The submission form accepts manuscript links rather than direct uploads. Dropbox, Google Drive, OneDrive, or any accessible share link will work.
